### Escape Room — Quem cometeu o crime?

**Jogo investigativo interativo | Estruturas de Dados**

Escape Room investigativo desenvolvido em equipe para o evento Fatec Portas Abertas, com o objetivo de transformar conceitos de Estruturas de Dados em desafios interativos. Os participantes assumem o papel de investigadores e precisam resolver enigmas, interpretar pistas e analisar evidências para descobrir quem cometeu o crime.

O jogo foi estruturado em cinco etapas, incluindo desafios baseados em **pilhas e deque**, que exigem raciocínio lógico, compreensão das operações e resolução de problemas sob limite de tempo.

O projeto foi apresentado ao público durante o evento, proporcionando uma experiência prática que conecta tecnologia, criatividade e trabalho em equipe.
